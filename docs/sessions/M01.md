# M01 · Canvi de nom a PassiMaker

- **Estat:** criteris complerts en local; pendent la CI a Windows i la fusió.
- **Branca:** `bloc/M01-passimaker`
- **Decisió:** 0006.

## Fet
- `git mv src/passi src/passimaker` i tots els imports, cadenes de mòdul i docstrings.
- `pyproject.toml`: paquet `passimaker`, ordres `passimaker`, `passimaker-nou` i `passimaker-render`, `packages` i
  `filterwarnings`. `uv.lock` regenerat (només canvia el nom del paquet).
- Extensió `.passimaker` (`projectio.EXTENSION`, `RECOVERY_FILE_NAME`) i format `"passimaker"` al JSON (`FORMAT_NAME`).
- `PassiError` → `PassiMakerError` i `PASSI_FFMPEG` → `PASSIMAKER_FFMPEG`.
- `tools/obtenir_ffmpeg.ps1`: carpeta temporal `passimaker-ffmpeg-…`.
- `.gitignore`: la regla dels temporals passa a `*.passimaker.*.tmp`. L'antiga (`*.passi.tmp`) no coincidia amb el nom
  real dels temporals (`.<nom>.<atzar>.tmp`).
- Documents vius (`CLAUDE.md`, `README.md`, `PLA.md`, `CONTRACTES.md`, `ESPECIFICACIO.md`): nom visible, camins,
  ordres, extensió, `PassiMaker.exe`, ZIP i carpetes d'usuari. **Els prompts dels blocs a `PLA.md` ja apunten a
  `src/passimaker/`.**
- Notes de sessió i decisions: només camins, noms de mòdul i el text proposat per al B10 a `B01.md`
  ("versió més nova de PassiMaker"). La 0003 conserva la D1 original amb una nota que remet a la 0006.
- Dues línies de més de 110 caràcters per culpa del nom més llarg, partides (`cli.py`, `model/types.py`).
